# mame4all (MiyooCFW)

Port of MAME 0.37b5 for the MiyooCFW (with ODx frontend)

### Native build (linux):

```
make DEBUG=1
```

### Cross-Compile build (MiyooCFW):

- compile binary (e.g. via docker):
```
make
```

- or generate IPK package:
```
gm2xpkg
```
